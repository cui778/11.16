# Minimal Web Package for the 11.16 SWMM Diagnosis Project

This branch is a lightweight package for web-side reading, thesis writing, and PPT reconstruction.

It intentionally excludes raw data, model checkpoints, large simulation outputs, and old experiment history.

## Recommended Reading Order

1. `GITHUB_UPLOAD_SCOPE.md`
2. `script2_new/chapter3_data_generation/README.md`
3. `script2_new/chapter3_data_generation/plans/CH3_PROTOCOL_FREEZE.md`
4. `script2_new/chapter4_diagnosis_model/README.md`
5. `script2_new/chapter4_diagnosis_model/plans/CH4_PROTOCOL_FREEZE.md`
6. `script2_new/chapter5_layout_optimization/README.md`
7. `script2_new/chapter5_layout_optimization/plans/CH5_CORE_BUDGET_PERFORMANCE_MANIFEST.md`

## Main Use

- Use Chapter 3 files to understand SWMM data-generation protocol.
- Use Chapter 4 files to understand diagnosis model experiments and formal result summaries.
- Use Chapter 5 files to understand monitoring layout methods and evidence.
- Use `script2_new/experiments/tables/` for lightweight result tables.

For final chapter text and PPT source data, use the companion repository:

`https://github.com/cui778/thesis_writing_repo`

This package is only the code/provenance companion.
