# 第一章实验计划：面向排水管网缺陷定位的模型创新

日期：2026-03-11

---

## 1. 章节定位

第一章的核心任务不是比较传感器布置策略本身，而是：

> 在给定监测点集 `S`、候选缺陷节点集 `C` 和统一数据生成协议的条件下，提出并验证一种更适合排水管网缺陷传播机理的缺陷定位模型。

因此，第一章需要回答的主问题是：

1. 通用时序/图模型是否足以完成该任务？
2. 面向排水管网传播机理的模型设计，能否显著提升定位精度与泛化能力？
3. 模型性能是否依赖某一种特定输入表示（raw / residual）或特定候选空间设定？

第一章结束时，应得到：

- 一个可信的、可复现的缺陷定位主模型；
- 一套固定的数据协议，供第二章监测点优化直接调用；
- 对 baseline / residual / 候选空间 / 泛化能力的清晰认识。

---

## 2. 第一章与第二章的衔接

整篇论文的叙事建议如下：

- 第一章解决“**怎么识别缺陷**”：固定监测点条件，研究模型创新。
- 第二章解决“**怎么看到缺陷**”：固定第一章最优模型，研究监测点优化。

因此，第一章中已有的 degree / betweenness / downstream / observability / random / full 等监测点策略，不再作为第一章主变量，而作为：

- 固定主设定时选取 `S` 的依据；
- 第一章末尾的稳健性/补充实验；
- 第二章的 baseline 对照方法。

## 3. 第一章的研究假设

### H1. 通用 GCN 未必适合排水管网缺陷定位

已有结果表明：

- `gru_only` 在 scenario 划分下优于 `gru_gcn`；
- `gru_gcn` 在 node-holdout 下明显退化；
- `hydraulic_inverse` 在 scenario 与 node-holdout 下均优于 `gru_gcn`，且优于 `gru_only`。

这说明：

> 排水管网缺陷定位所需的空间先验，并不能通过普通邻域聚合型 GCN 充分表达；更有效的做法应显式利用传播方向、路径或监测感知关系。

### H2. 模型创新应建立在“物理感知的时空建模”上

第一章模型创新应围绕以下方向展开：

- 时间路径：捕捉监测序列中的异常动态模式；
- 空间路径：利用排水管网的有向传播关系；
- 监测感知聚合：建模“某候选缺陷节点最可能通过哪些监测节点被观测到”。

### H3. baseline / residual 是输入表示与稳健性问题，不是第一章主创新

第一章承认正常工况存在动态波动，但不把 baseline 学习作为本章核心创新。baseline 与 residual 的角色定义为：

- 输入表示的标准化手段；
- 对模型稳健性进行验证的实验变量；
- 后续多工况扩展的铺垫。

## 4. 第一章固定项与主设定

为保证“模型创新”这一主问题不被其他变量污染，第一章主实验需固定如下设置。

### 4.1 固定的节点集合

- 全网节点集 `V`：128 个节点
- 候选缺陷节点集 `C`：主设定固定为 `50` 个节点
- 监测节点集 `S`：主设定固定为 `25` 个节点

其中：

- `C=50` 代表工程先验筛选后的高风险候选空间；
- `S=25` 代表预算受限下的监测点数量；
- 第一章主实验固定 `S`，第二章再研究 `S` 的优化。

### 4.2 主监测点设定

建议第一章主设定使用：

- `S = downstream, N=25`

理由：

- 你当前结果中 downstream 在多种策略中表现最优或接近最优；
- 与“缺陷信号顺流传播到监测点”的物理叙事一致；
- 可作为第二章优化前的较强 baseline。

### 4.3 主缺陷矩阵协议

第一章主实验应固定单一缺陷矩阵协议，建议：

- 缺陷矩阵：`defect_matrix_diverse.csv`
- 场景数：`300`
- 类型比例：`I:E:P = 40:40:20`
- 时间模式：`diverse`
- 强度集合：沿用当前 `30/40/50`

原则：

> 第一章主实验中，缺陷矩阵是控制变量，不是主比较变量。

### 4.4 baseline / residual 主设定

建议主设定如下：

- baseline：采用**单一综合 baseline**
- 输入主版本：优先使用 `raw + residual` 或 `raw`，不把 `residual-only` 作为唯一主方案

更具体地说：

- 你当前 baseline 并非完全静态常数，而是包含入流变化、日变化系数和扰动的综合正常工况；
- 因此它可以作为第一章的受控参考工况；
- 但由于当前只有一个 baseline regime，不能把 residual 解释为“对所有正常工况都成立的标准化”。

因此，第一章对 residual 的处理原则是：

> residual 可以做，但其主要作用是辅助标准化与稳健性验证，而非主创新本身。

### 4.5 主评估划分

第一章采用两类划分：

1. **scenario split**：主结果
   - 回答模型在已知候选节点集合下的定位能力；
2. **node-holdout split**：泛化结果
   - 回答模型对未见过缺陷节点的泛化能力。

## 5. 第一章模型创新路线

## 5.1 模型主线

建议第一章最终模型路线定义为：

> 基于时间编码 + 物理感知空间传播 + 监测感知聚合的缺陷定位模型

你当前已有的结果最支持的方向是：

- `gru_only`：说明时序本身很强；
- `gru_gcn`：说明通用 GCN 不匹配任务；
- `hydraulic_inverse`：说明显式物理路径先验有效。

因此，最终模型建议以以下结构为主线：

1. **时间编码器**
   - GRU 起步，必要时可升级为更强时序编码模块；
2. **空间传播模块**
   - 不采用普通 GCN 邻域平均作为最终方案；
   - 优先采用 `hydraulic_inverse` 一类的路径/方向先验；
3. **监测感知聚合模块**
   - 建议加入 candidate-to-monitor 的 cross-attention 或同类注意力机制；
4. **输出头**
   - 定位主任务；
   - 可选：缺陷类型辅助头（I/E/P）。

### 5.2 本章希望最终证明的结论

第一章最终应证明：

1. 你的模型优于通用 baseline（time_mean_linear / gru_only / gru_gcn）；
2. 模型提升不是来自参数堆积，而是来自物理感知模块；
3. 模型在 node-holdout 下仍具优势，说明其不是单纯记忆；
4. 模型不依赖某一种特定输入表示；
5. 在候选空间变化时，模型结论仍有解释力。

## E4. 输入表示稳健性：raw / residual / raw+residual

目的：说明模型结论不依赖某一种手工输入表示。

### E4.1 建议对比

- `raw only`
- `residual only`
- `raw + residual`

若时间允许，可追加：

- `matched multi-baseline residual`（作为扩展，不作为第一章主线前提）

### E4.2 实验意义

这组实验回答的不是“残差是不是创新点”，而是：

1. 你的模型是否必须依赖 residual 才有效？
2. residual 是否在当前单 baseline 设定下提供额外增益？
3. 模型是否具备从 raw 中自动学习异常偏离的能力？

### E4.3 如何解释当前 B3 结果

当前已有结果表明：

- raw 与 residual 差异不大；
- raw 略优但波动更大；
- residual 未带来决定性提升。

因此，E4 的合理结论目标是：

> 你的模型不依赖特定手工残差特征才能成立；residual 作为辅助标准化手段可改善部分稳定性，但不是性能提升的唯一来源。

## E5. 候选空间实验：C=50 vs C=128

目的：回答审稿人/答辩中最自然的问题：

> 为什么不直接在全网 128 个节点上做定位？

### E5.1 对比设定

- `C = 50`
- `C = 128`

### E5.2 固定条件

- 统一 `S = downstream_N25`
- 同一模型
- 同一训练协议
- 同一缺陷矩阵生成规则（仅候选空间变化）

### E5.3 预期叙事

- `C=128`：无先验、全网搜索、任务更难、结果更低但更通用；
- `C=50`：融入工程先验、缩小搜索空间、结果更高；
- 两者共同说明：你的模型既能处理广泛候选空间，也能从先验知识中受益。

### E5.4 论文价值

这组实验非常关键，因为它把“候选空间的工程合理性”转化为“可量化验证”的结果，而不是停留在口头解释。

## 7. baseline / residual 的统一处理原则

这是第一章最容易被问到、但也最容易讲清楚的地方。

### 7.1 本章推荐立场

1. baseline 不是第一章创新点；
2. residual 不是第一章主结论的前提条件；
3. baseline / residual 的作用是帮助定义“正常波动背景下的异常偏离”；
4. 第一章主要在单一综合 baseline 设定下进行；
5. 多工况 baseline 属于后续扩展方向，而非本章必须完成的前提。

### 7.2 论文中可直接使用的表述

> 本章采用带有日变化系数与随机扰动的综合正常工况作为单一 baseline，用以近似表征日常运行波动。在此基础上构造 residual 特征，以辅助描述当前观测相对于参考工况的偏离程度。需要指出的是，baseline 与 residual 在本章中主要承担输入表示与稳健性验证的角色，而非本文核心创新。多工况条件下的 baseline 匹配与动态工况鲁棒性问题，可作为后续章节或未来工作的进一步研究方向。

### 7.3 第一章不建议做的事

在第一章中，不建议把下列内容抬升为主线：

- 自适应 baseline 学习
- 多工况 baseline 自动匹配
- 基于工况识别的 residual 路由

这些内容若要做，更适合作为第三章或后续扩展。

## 11. 本章一句话总结

第一章不再回答“哪种监测点策略最好”这一问题本身，而是回答：

> 在固定监测条件与统一数据协议下，什么样的模型设计最适合排水管网缺陷定位，并且能够在不同输入表示、不同候选空间和未见节点上保持有效。

这一定义清楚后，第二章就可以顺理成章地接着研究：

> 在第一章模型固定后，如何进一步优化监测点布置，使模型获得更高的定位性能。
