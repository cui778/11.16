# 研究方案：排水管网缺陷定位与传感器布置优化

---

## 一、整体研究框架

### 研究问题
在传感器数量有限的条件下：
1. 如何布置传感器能最大化缺陷定位能力？（第一章）
2. 如何在规则方法基础上进一步优化传感器布置？（第二章）

### 两章的逻辑关系
```
框架验证（当前 script2_new 实测）
  25 节点监测（如 degree/downstream）：MRR≈0.88–0.91，框架有效 ✅
  128 节点全监测（A0/full，对照）：MRR≈0.64，说明无结构地使用全节点反而更差，精选监测点必要

第一章
  输入：监测节点S（25个，按规则选）
  输出：候选节点C（50个）
  目的：比较不同传感器布置规则的定位性能，找到最优规则

第二章
  输入：优化后的监测节点S*（25个）
  输出：候选节点C（50个）
  目的：在第一章最优规则基础上，用优化算法进一步提升定位性能
```

## 二、关于候选节点集C的定义（你的问题）

**候选节点集C能不能一直改变？**

不建议改变。原因如下：

C的定义是"可能发生缺陷的节点集合"，在实际工程中对应"历史上发生过缺陷、或管道老化严重、或拓扑关键位置的节点"。一旦定义了管网的物理特性，C就应该固定。

你现在用中心度+空间分散度选出50个候选节点，这个选法有明确的物理依据，应该贯穿整个研究。

**唯一需要注意的是：** 缺陷矩阵的节点必须完全来自C，这一点已经在script2_new中保证了。

## 三、关于第二章的科学性（你的纠结）

你说得对，单纯用中心度规则的对比太简单，称不上"优化"。第二章需要提出一个有科学依据的优化框架。

**第二章的核心创新点应该是：**

> 将传感器布置问题建模为"最大化缺陷可观测性"的组合优化问题，结合管网水力传播特性，提出一种数据驱动的传感器布置优化方法。

具体来说：

**第一步（建模）：** 定义可观测性指标
```
Obs(S, C) = (1/|C|) × Σ_c [S ∩ influence_set(c) ≠ ∅]
```
即：监测节点集S对候选节点集C中每个节点的缺陷信号的平均覆盖率。

**第二步（优化）：** 在Obs基础上加入模型反馈
- 第一章的规则方法只用图拓扑信息（静态）
- 第二章用训练好的模型评估每种布置的实际定位性能（动态）
- 优化目标：找到使MRR最大的25个节点组合

**第三步（算法）：** 用贪心+局部搜索
- 初始化：用第一章最优规则的结果作为起点
- 每轮：尝试替换一个监测节点，用模型评估MRR变化，保留提升
- 终止：MRR不再提升

这个方案的科学性在于：把"传感器布置"和"定位模型性能"显式耦合，比单纯的图论方法更有针对性，也比遗传算法更容易解释。

## 六、第二章研究方案（概要）

### 核心方法：模型引导的传感器布置优化

**与第一章的区别：**
- 第一章：静态规则 → 固定的传感器布置
- 第二章：动态优化 → 利用模型反馈迭代改进传感器布置

**算法框架：**
```
输入：第一章最优规则得到的初始布置S0，候选节点集C，训练好的定位模型M
输出：优化后的传感器布置S*

算法（贪心局部搜索）：
1. S = S0（用第一章最优策略初始化）
2. 用S训练模型M，得到基准MRR0
3. 对每个候选替换操作（换入节点v，换出节点u）：
   a. 生成新布置S' = S - {u} + {v}
   b. 用S'重新训练模型，得到MRR'
   c. 记录(u, v, ΔMRR)
4. 选ΔMRR最大的操作，执行替换
5. 重复3-4直到MRR不再提升
```

**科学性来源：**
- 优化目标直接是模型定位性能（MRR），不是间接的图论指标
- 利用了水力传播信息（通过模型隐式学习）
- 可以分析最优布置的图拓扑特征，给出物理解释

**计算成本控制：**
- 每次替换操作需要重新训练，成本高
- 可以用"只微调不从头训练"降低成本（用S0训练的模型作为初始权重）
- 或者用可观测性指标作为代理目标（不需要重新训练）快速筛选候选操作
